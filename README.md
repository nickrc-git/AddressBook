# Address Book Management System

## Overview
A menu-driven Address Book application developed in C for managing contact information efficiently.

## Features
- Add contacts
- Search contacts
- Edit contacts
- Delete contacts
- Sort contacts
- File-based storage

## Technologies Used
- Advanced C
- Structures
- Arrays
- File Handling
- String Manipulation

## Learning Outcomes
- Modular programming
- File I/O operations
- Data management using structures
- Input validation techniques
